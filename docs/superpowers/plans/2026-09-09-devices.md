# Devices & QR Code Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement CRUD for Devices, QR Code generation and scanning, Software assignments, and Maintenance Logs.

**Architecture:** We use Next.js 14 App Router with Server Actions instead of API routes for data mutations to keep things secure and simple. Zod handles validation. Shadcn UI for components. `qrcode` for generating QR images, and `html5-qrcode` for scanning them.

**Tech Stack:** Next.js 14, Prisma, PostgreSQL, Zod, React Hook Form, Tailwind CSS, Shadcn UI, qrcode, html5-qrcode.

**Spec:** `specs/03-devices.md`

## Global Constraints

- Strict TypeScript.
- Server Components by default, add `"use client"` only when hooks or interactivity are needed.
- Only ADMIN or TECHNICIAN can create/update/delete devices. USER can view and scan QR.
- All database calls must be securely authenticated using NextAuth session.

**Files:**

**Interfaces:**

- Consumes: Zod schemas from Task 1, Prisma DB context (`src/lib/db.ts`).
- Produces: `createDevice`, `updateDevice`, `deleteDevice`, `addMaintenanceLog`, `addSoftware`, `removeSoftware`.

- [ ] **Step 1: Write Device Actions**
      Create `src/app/actions/device-actions.ts` with `"use server"`.
      Check session for `ADMIN` or `TECHNICIAN`.
- `createDevice`: generates `qrCode` (`DEVICE-${cuid()}`), creates device.
- `updateDevice`: updates device.
- `deleteDevice`: soft deletes device (`deletedAt = new Date()`) (ADMIN only).
  Call `revalidatePath` for `/dashboard/devices` and `/dashboard/devices/[id]`.

- [ ] **Step 2: Write Relation Actions**
      In the same file, implement `addMaintenanceLog`, `addSoftware`, `removeSoftware`.
