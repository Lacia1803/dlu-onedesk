# FAQ / Knowledge Base Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create an FAQ / Knowledge Base system where Admins/Techs can manage guides and Users can view/search them to solve issues before opening a ticket.

**Architecture:** We use Next.js Server Components for data fetching and Server Actions for mutations. Shadcn Accordion will be used for the FAQ display.

**Tech Stack:** Next.js 14, Prisma, PostgreSQL, Zod, React Hook Form, Shadcn UI (Accordion, Input, Dialog, Select).

**Spec:** `specs/06-faq.md`

## Global Constraints

- Strict TypeScript.
- Server Components by default.
- Users can view active FAQs. Techs/Admins can CRUD FAQs.

### Task 2: Server Actions

**Files:**
- Create: `src/app/actions/faq-actions.ts`

**Interfaces:**
- Consumes: Zod schema, DB context.
- Produces: `createFaq`, `updateFaq`, `deleteFaq`.

- [ ] **Step 1: Write FAQ Actions**
Create `src/app/actions/faq-actions.ts` (`"use server"`).
- `createFaq(data)`: Check if `ADMIN` or `TECHNICIAN`. Save data with `authorId` = `session.user.id`.
- `updateFaq(id, data)`: Check permissions, update.
- `deleteFaq(id)`: Check permissions. Perform soft delete by setting `isActive = false` or physically delete if `isActive` is just a toggle (let's do physical delete for simplicity or just rely on the `isActive` boolean for hiding). *Wait, the model doesn't have deletedAt, so we use physical delete or toggle isActive*.
